# 장소에 저장된 게시물 모아보기 페이지

## 목적

장소 시트가 저장된 게시물마다 카드를 통째로 펼쳐 세로로 쌓는다. 게시물이 여러 건인 장소에서는
그 아래 "게시물에 포함된 장소" 섹션까지 한참 밀려나 시트 안에서 장소를 훑기 어렵다.
시안(`8월 19일 작업`)대로 여러 건일 때는 시트에 미리보기만 두고 전체는 별도 페이지로 뺀다.

작업 중 `GET /api/v1/places/{placeId}` 가 게시물을 페이지로 내려주는데(`page`/`size`, 기본 20)
프론트가 파라미터를 넘기지 않고 `items` 만 읽어 `hasNext`·`totalElements` 를 버리고 있는 걸
확인했다. 그래서 **21건째부터는 어떤 화면에서도 볼 수 없고** 개수 표기도 20에서 멈춘다.
전체를 보여주는 게 목적인 새 페이지에서 특히 어긋나므로 함께 연동한다.

## 범위

* 장소 시트의 저장 게시물 섹션을 게시물 수로 분기한다.
  * 1건: 지금처럼 게시물 카드를 그대로 펼친다.
  * 2건 이상: `저장된 게시물 N >` 헤더 + 가로 카드 목록만 둔다. 헤더는 제목·개수·화살표를
    한 버튼으로 묶어 줄 어디를 눌러도 모아보기 페이지로 이동한다.
* 가로 카드는 시안 `List` — 167x208 썸네일 + 제목 + `계정 · N Places`. 이미지가 2장 이상인
  게시물은 썸네일 우상단에 여러 장 표시를 얹는다.
* 모아보기 페이지(`/place/{placeId}/posts`)를 추가한다. 시트와 같은 게시물 카드를 세로로
  나열하되 카드의 제목 줄은 화면 헤더가 대신하므로 끈다.
* 장소 상세의 게시물 페이지네이션을 연동한다. 모아보기 페이지는 끝까지 스크롤하면 다음
  페이지를 이어 붙이고, 시트 헤더의 개수는 첫 페이지 건수가 아니라 전체 건수를 쓴다.
* 무한 스크롤 sentinel 코드가 세 번째로 복사될 자리라 공용 훅으로 뽑고, 기존 두 화면
  (아카이브 상세·공유 아카이브)도 그 훅을 쓰게 옮긴다.

## 제외범위

* **게시물 상세 N+1 호출 최적화.** 카드마다 `posts/{postId}` 를 부르는 구조는 그대로 둔다.
  시트의 가로 카드가 상세를 필요로 하는 건 이미지 장수와 연결된 장소 수 둘뿐이라, 서버가
  `PlacePostResponse` 에 이 두 카운트만 실어주면 시트 쪽 호출은 통째로 사라진다 → BE 논의 필요.
* **시트 가로 목록의 전체 페이지 로딩.** 시트는 미리보기라 첫 페이지(최대 20건)까지만 그린다.
* **시트 → 페이지 진입 시 `places/{placeId}` 1회 중복.** 쿼리 키가 달라 생기는데, `staleTime`
  이 30초라 캐시를 수동으로 넘겨도 곧 재요청될 값이라 그대로 둔다.
* **공유 아카이브의 장소 시트(`SharedPlaceSheet`).** 별도 컴포넌트라 이번 분기와 무관하다.

## 유의사항

* **장소별 게시물 전용 엔드포인트가 없다.** 페이지를 넘길 때마다 사진·태그·영업시간까지 실린
  장소 상세 전체가 재전송된다. `/api/v1/places/{placeId}/posts` 같은 엔드포인트가 생기면
  `fetchPlacePosts` 하나만 갈아끼우면 된다.
* **무한 스크롤은 자동 테스트로 덮지 못한다.** 테스트 셋업의 IntersectionObserver 스텁이 교차
  콜백을 발생시키지 않는다(기존 아카이브 목록도 같은 이유로 테스트가 없다).
  **게시물이 20건 넘는 장소로 수동 확인이 필요하다.**
* **저장 게시물 섹션은 시트를 맨 위(full)까지 올려야 렌더된다.** 핀을 눌러 열린 기본 높이에서는
  보이지 않으므로, 확인·QA 시 시트를 끝까지 끌어올려야 한다.
* **가로 카드를 누르면 그 게시물 상세로 보낸다.** 시안에 없는 동작이라 확인이 필요하다.
  누르면 아무 일도 없는 카드로 두지 않으려는 판단이었고, 모아보기 페이지로 보내는 게 맞으면 바꾼다.
* **1건일 때 카드를 펼치는 분기**는 시안 주석 `다중 게시물일 경우 페이지 추가 됨` 을 근거로
  했다. 1건도 헤더를 달아야 하면 분기만 지우면 된다.
* sentinel 훅 추출로 이번 기능과 무관한 화면 두 개를 함께 건드렸다. 리뷰 범위가 부담되면
  그 커밋만 떼어낼 수 있다.

## 성공기준

* [ ] 게시물 2건 이상인 장소에서 시트에 `저장된 게시물 N >` 헤더와 가로 카드 목록이 보인다.
* [ ] 헤더의 제목·숫자·화살표 어디를 눌러도 모아보기 페이지로 이동한다.
* [ ] 게시물 1건인 장소는 기존처럼 카드가 그대로 펼쳐진다(헤더 없음).
* [ ] 게시물이 20건을 넘는 장소에서 헤더 숫자가 실제 전체 건수와 일치한다.
* [ ] 모아보기 페이지를 끝까지 스크롤하면 21번째 이후 게시물이 이어 붙고,
      `places/{placeId}?page=1&size=20` 요청이 나간다.
* [ ] 모아보기 페이지에서 뒤로 가면 시트가 보던 높이로 복원된다.
* [ ] 아카이브 상세·공유 아카이브의 무한 스크롤이 기존과 동일하게 동작한다.
* [ ] `pnpm -r typecheck` · `pnpm lint:ci` · `pnpm -r test` · `pnpm web:build` 통과.
