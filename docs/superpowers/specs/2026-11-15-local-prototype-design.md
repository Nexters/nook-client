# 로컬 프로토타입 목 데이터

목적: 현재 develop의 최신 화면에서 로그인 후 상태와 충분한 콘텐츠를 확인하고 UI를 수정한다.

구성: 웹 개발 환경에서 명시적으로 켠 목 모드에 한해 자동 로그인한다. 성수 일대 샘플 장소 30개와 각 10개를 담는 아카이브 3개를 제공한다. 아카이브 목록·상세, 지도·장소 상세, 게시물 상세, 사용자 프로필에 기존 API 응답 형식의 로컬 데이터를 공급한다. 아카이브 생성·수정·삭제, 메모·북마크 수정은 브라우저 저장소에 유지한다. 지원하지 않는 요청은 명시적으로 실패시키며 실제 API로 전달하지 않는다. 운영 빌드와 실제 인증에는 적용하지 않는다.

접근 비교: 실제 개발 서버를 사용하는 방식은 유효한 로그인이 필요하다. 사용자는 로컬 목 데이터를 선택했다. 기존 UI를 복제하는 방식은 최신 UI와 어긋날 수 있으므로 기존 API 경계에서 데이터를 대체한다.

제약: 개발 서버의 장소 검색은 비로그인 요청에 HTTP 401을 반환했다. 따라서 장소는 서버에서 가져온 데이터가 아닌 샘플임을 명시한다. 서버의 계정이나 데이터는 변경하지 않는다. 지도 인증은 네이버에 localhost:5174가 등록되어 있어야 한다.

검증: 장소 수·아카이브 연결·페이지네이션·수정 유지·실제 서버 호출 차단을 확인하고 웹 타입 검사와 관련 테스트를 실행한다. 브라우저 접근이 가능하면 목록과 상세의 렌더링을 확인한다.
