# 로컬 UI 프로토타입

`apps/web/.env.development.local`에 `VITE_LOCAL_PROTOTYPE=true`를 설정하고 개발 서버를 시작한다.

```sh
corepack pnpm --filter web dev --port 5174
```

- 375×812 미리보기: http://localhost:5174/prototype.html
- 진입: http://localhost:5174/archive
- 지도: http://localhost:5174/map
- 기존 디자인·컴포넌트·화면 인터랙션을 사용한다.
- 로그인 사용자, 샘플 장소 30개, 게시물 30개, 아카이브 3개를 제공한다.
- 장소명·좌표·주소·사진은 화면 확인용 샘플이며 실제 서버에서 가져온 정보가 아니다.
- 아카이브 생성·수정·삭제, 게시물 이동·삭제·장소 연결, 메모·북마크 변경을 로컬에 저장한다.
- 저장소 키 `nook.local-prototype.v1`을 삭제하면 샘플이 초기화된다.
- 플래그를 false로 바꾸면 실제 API 모드로 돌아간다. 운영 빌드는 이 플래그를 무시한다.
- 지원하지 않는 요청은 로컬 오류를 반환하며 실제 서버로 전달하지 않는다. 네이티브 전용 동작과 업로드는 모사하지 않는다.
- 네이버 지도는 localhost:5174가 해당 Client ID의 허용 URL에 등록되어 있어야 표시된다.

장소는 서울 6개 동네에 분산되어 확대에 따라 클러스터가 나뉜다. 기존 저장 데이터의 좌표도 수정 내용은 보존하며 자동 갱신한다.

## 검색 결과 카드 (Figma 40:1944)

기본 카드에서는 검색어 헤더를 상단에 유지하고, 전체 확장에서는 숨긴다. 검색 결과는 12px 바깥 여백의 플로팅 카드로 보여주며, 제목은 H2(18px), 사진은 319:198 비율을 사용한다. 현재 위치 버튼은 카드의 실제 높이에서 16px 위에 둔다. 카드/사진/핸들을 위로 끌거나 핸들을 누르면 기존 PlaceSheet 전체 상세로 연결되며, 기존 상세와 같이 전체 화면을 채운다. 기본 높이로 내리면 검색 헤더와 플로팅 카드가 복원된다. 해시태그가 없어도 태그 한 줄 높이(24px)는 유지한다 — **태그 없을 때 영역 처리는 미정**(후보: 사진이 빈 높이를 가져가기, 아카이브 이름·동네 같은 고정 태그 넣기). 상세 닫기는 같은 검색 결과 카드로, 상단 뒤로가기는 검색 결과 목록으로 돌아간다. iOS의 실제 터치 감각은 실기기 검증이 필요하다.

## QA 리모컨과 iOS 미리보기

375×812 화면 우측 하단의 작은 QA 리모컨을 누르면 사진 6장/1장/없음 × 태그 있음/없음의 6가지 조합을 선택할 수 있다. 각 케이스는 별도 로컬 저장소를 사용해 일반 목 데이터의 수정 내용과 섞이지 않는다. 첫 장소가 선택한 케이스이고 이후 장소는 비교용 기존 데이터다. 이전/다음 장소, 전체 확장, 카드로 접기, 검색/키보드 명령을 제공한다.

상태바(54px)와 홈 인디케이터(20px)는 투명 오버레이다. iframe은 812px 전체를 채우고, 미리보기에서만 CSS env()를 안전 영역 변수로 바꿔 실제 기기와 유사한 레이아웃을 보여준다. 샘플 키보드가 나타나면 iframe은 521px로 줄어든다. 이는 실제 iOS 키보드/제스처 재현 테스트를 대체하지 않는다.

접힌 플로팅 카드(Figma 42:2832)는 사진과 인디케이터를 숨기고 제목·주소·액션·태그를 유지한다. 기본 카드에서 아래로 드래그하면 접히고, 접힌 카드에서 위로 드래그하면 사진 카드, 다시 위로 드래그하면 전체 상세가 된다. 리모컨의 접힌 카드 버튼으로 바로 확인할 수 있다. 전체 상세에서는 검색창을 숨기고, 카드 상태로 돌아오면 복원한다.


### 장소 미연결 게시물 리마인드 (NOOK-419)

- `prototype.html?reminder=12`로 아카이브 미리보기 진입.
- 아카이브 QA 리모컨: 0개 / 안내형 / 1개 / 2개 / 3개 / 12개. 4개 이상은 세 번째 썸네일에 나머지 개수 표시.
- 이미지 케이스는 안내형으로 시작해 900ms 읽기 대기와 썸네일 로딩이 끝나면 560ms 동안 펼쳐짐. 사진은 같은 가감속 곡선으로 480ms 동안 가운데에서 퍼지고 0/45/75ms 간격으로 겹쳐 등장해 시안 각도로 정착. 모션 줄이기에서는 즉시 표시.
- 다시 보기 버튼은 현재 데이터를 유지하고 애니메이션만 재생. 케이스 선택·초기화는 해당 로컬 데이터와 설정을 초기화.
- X는 이번 진입만 닫기, 다시 보지 않음은 로컬 리마인드 설정 OFF. 게시물 보기는 실제 미연결 게시물 목록과 기존 장소 추가 흐름으로 연결.
- 지도에서는 기존 카드·사진·태그·스와이프 설정만 표시. 아카이브로 돌아오면 마지막 리마인드 케이스 복원. 게시물 상세·마이에서는 리모컨 숨김.
- 샘플 썸네일 3장은 제공된 Figma 시안 이미지. 서버 API 또는 실제 데이터를 변경하지 않음.

- 다시 보지 않음 성공 시 기존 action 토스트로 설정 변경 안내와 취소 버튼 표시. 취소하면 리마인드 설정을 다시 켜고 배너 복원.


### 장소 롱프레스 메뉴 목업 (NOOK-418)

- `prototype.html?demo=place-menu`에서 내 아카이브의 장소 탭으로 바로 진입.
- 기존 장소 카드에서 터치/마우스 700ms 길게 누르기 또는 PC 우클릭 → 배경 블러와 iOS 스타일 반투명 공유·삭제 메뉴. 썸네일 미리보기 없음. 아이콘은 NOOK 공통 아이콘 사용.
- 스크롤/드래그 시 롱프레스 취소. 외부 클릭·Escape·앱 뒤로가기로 메뉴 닫기.
- 공유는 장소의 네이버 지도 검색 링크 복사. 삭제는 확인 후 현재 화면에서만 제거하고 토스트 취소로 복원. 서버/로컬 저장 데이터 변경 없음.
- 공유받은 아카이브 장소에는 삭제 액션 없음. 로컬 프로토타입에서만 활성화.
- QA 리모컨 > 아카이브 > 장소 롱프레스 메뉴 목업으로도 진입.


### 게시물 단독 공유 (NOOK-369)

- `prototype.html?demo=post-share` 또는 아카이브 QA 리모컨의 게시물 공유받기 목업.
- 기존 게시물 공유 메뉴에서 발급한 `/shared-post/:token` 링크는 서버의 공개 스냅샷 조회 API에 연결.
- 공유 대상은 게시물 하나와 공유 시점의 연결 장소 전체. 연결 해제된 장소, 개인 메모·북마크·아카이브 정보 제외.
- 미저장자는 `내 아카이브에 저장` → 내 소유 아카이브 선택 → 저장 후 내 게시물 상세.
- 이미 저장했다면 서버 `viewerSavedPostId` 기준으로 `내 게시물 보기`. 저장 API의 `alreadySaved`면 기존 메모/장소 보존.
- 로컬에서도 공유 스냅샷을 복사해 독립적으로 저장. 원본 삭제 시 링크 만료, 저장한 복사본은 유지.
- 티켓의 스냅샷/중복 저장 정책 미결 항목은 임의로 확정하지 않고, 현재 생성된 서버 get3/save1 API 계약을 따름.


### 지도 장소 목록 규격 (Figma 56:3703)

- `prototype.html?demo=map-grid`, 또는 지도 QA 리모컨의 장소 목록 규격 보기.
- 지도 목록·검색 결과에만 `PlaceCard variant="map"`: 167:134 썸네일 비율, 8px 사진/텍스트 간격, 12px 장소명/메타, 텍스트 하단 6px.
- 좌우 16px, 2열·열/행 간격 8px. 아카이브 카드는 기존 세로 비율 유지.
- 검색창 44px/라운드 12px, Figma 검색20/필터24 아이콘 적용.
- 최신순/오래된순/가까운순은 서버 sort 파라미터 사용. 정렬 변경 시 쿼리 키와 커서 초기화, 가까운순은 선택 당시 GPS 좌표를 페이지 전체에서 고정. 위치가 없으면 가까운순 선택 불가.


### 아카이브 보기 옵션 (Figma 59:4154 / 61:4976)

- `prototype.html?demo=archive-view` → 더보기 → 아카이브 필터.
- 정렬: 최신순/오래된순. 보기: 피드형(큰 이미지 1열)/기본형(가로형 썸네일 2열)/리스트형(64px 썸네일 가로 행).
- 적용하기 전에는 초안만 변경. 닫기·뒤로가기·드래그 닫기는 초안을 버림.
- 아카이브 ID별 기기 로컬 저장. 공유받은 아카이브도 개인 보기 설정만 바뀌며 원본에는 영향 없음.
- 현재 아카이브 목록 API에 sort 파라미터가 없어 오래된순은 모든 페이지를 받은 뒤 서버 기본 순서를 반전. 데이터가 많은 아카이브는 서버 정렬 API가 필요함. 기본 최신순은 기존 무한스크롤 유지.

- 아카이브 더보기는 헤더에서 편집·공유 행 오른쪽으로 이동. 44×40px 회색 블록 버튼, 아래 16px 간격 드롭다운. 메뉴는 Figma 61:4847 원본 아이콘·문구·순서 적용(선택 편집은 기존 다중 선택 삭제 모드).
